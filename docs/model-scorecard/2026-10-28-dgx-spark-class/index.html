2026-10-28 · DGX Spark Class

A model scorecard round on Arm Cortex-X925 + Cortex-A725 (20 cores) · NVIDIA GB10 · 122 GB: 2 models across 4 task sets. Every round is listed in the model scorecard, with its results side by side in one table.

Arm Cortex-X925 + Cortex-A725 (20 cores) · NVIDIA GB10 · 122 GB · llama-cpp · 3 trials per task · 2026-10-28 · gezel 22fec991 · catalog 0.3.1

Qwen 3.8 27B Q4 and Gemma 4 12B Q4 on a DGX Spark (NVIDIA GB10, Linux) with native 0.1.54: llama.cpp on CUDA, with MTP speculative decoding on by default for both models. 258 trials, three per model and scenario, ran October 28–30, 2026; none was repeated or replaced, and every raw verdict is kept. Three failures are set aside as infrastructure: one Linux script-sandbox failure and two gates the model wrote itself, which the harness classed as setup failures. Evaluation homes had package scripts switched off, so bug-fix-tdd, codemod-sweep and refactor-module could not pass for either model; without those 18 trials the developer failure rate is 0/21 for Qwen and 7/21 for Gemma. docblocks-theme-roundtrip lacked its DocBlocks tools in all six trials, and the harness stopped two Qwen route-multi trials and one Qwen author-fanout trial while they were still progressing. Task speeds are engine-log medians over every attempt. Memory is not shown: the GB10 shares its memory with the GPU in a way the measurement cannot see. Artifact reviews are by Claude Sonnet 4.6, one column per rubric. The six A/B readout reviews used a mismatched rubric and seven reviews graded a starting or incidental page instead of the work, so those 13 are excluded.

Memory isn't shown for this round. This machine's graphics chip shares the computer's memory in a way our measurement can't see, so the number would read far below what the model really uses.

October 28–30 DGX Spark results and review data

Qwen 3.8 27B Q4 and Gemma 4 12B Q4 completed all 258 trials on a DGX Spark (NVIDIA GB10, Linux) with native 0.1.54: three per model and scenario across the four task sets. Qwen passed 106 of 129 and Gemma 90 of 129. Three failures are set aside as infrastructure: a gap in Linux script sandboxing, and two gates the model wrote itself, which the harness classed as setup failures.

Read the engineering set with care. Package scripts were switched off in the evaluation homes, so three tasks that need a test run could not pass for either model. The table keeps those 18 failures: Qwen failed 9 of 30 engineering trials and Gemma 16 of 30. Excluding them, Qwen failed 0 of 21 and Gemma 7 of 21. Docblocks-theme-roundtrip lacked its tools in all six trials, and the harness stopped three Qwen complex-workflow trials while they were still progressing. The reviewed report explains each case.

Claude Sonnet 4.6 reviewed 121 artifacts after the sweep. The Artifact reviews tables use 108 of them, one column per rubric. They exclude 13 reviews that used the wrong rubric or graded a starting page instead of the work; the other 137 tasks had no rubric to apply. The Task performance tables give output speed, prefill speed and wall time from the engine's logs for every attempt. Both models used speculative decoding, which is on by default. Memory is left out because this machine's shared memory is invisible to the measurement.
