A model scorecard round on AMD Ryzen 9 7950X3D 16-Core Processor · AMD Radeon AI PRO R9700 · 64 GB: 4 models across 2 task sets. Every round is listed in the model scorecard, with its results side by side in one table.

AMD Ryzen 9 7950X3D 16-Core Processor · AMD Radeon AI PRO R9700 · 64 GB · llama-cpp · 3 trials per task · 2026-09-04 · gezel f115c698 · catalog 0.1.55

Compares four sizes of Qwen 3.5 (2B, 4B, 9B and 27B, all Q4) on a Ryzen 9 7950X3D with a Radeon AI PRO R9700. Only general capability and office work were tested: models this size do not yet pass every general task, so the harder sets would mostly score zero. This computer has no NVIDIA graphics, so models ran on llama.cpp's Vulkan backend, and these results are not comparable to NVIDIA (CUDA) rounds.

System memory counts this computer's own memory only. What the model keeps on the separate graphics card isn't included.
