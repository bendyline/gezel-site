A model scorecard round on AMD Ryzen 9 7950X3D 16-Core Processor · AMD Radeon AI PRO R9700 · 64 GB: 2 models across 4 task sets. Every round is listed in the model scorecard, with its results side by side in one table.

AMD Ryzen 9 7950X3D 16-Core Processor · AMD Radeon AI PRO R9700 · 64 GB · llama-cpp · 3 trials per task · 2026-10-28 · gezel 22fec99111a5 · catalog 0.3.1

Six misaligned A/B reviews, seven incidental HTML reviews and 137 tasks with no applicable artifact review are excluded from these means. Both complete judge ledgers, corrected spreadsheet selections, capability-rubric differences, performance gaps and evaluator/setup findings are preserved in the R9700 downloadable report.

System memory counts this computer's own memory only. What the model keeps on the separate graphics card isn't included.

October 28–30 R9700 comparison and review data

This note also covers 2026-10-30 · Windows · Ryzen 9 7950X3D · Radeon AI PRO R9700.

The Qwen 3.8 27B Q4 and Gemma 4 12B Q4 comparison completed all 258 trials across four task sets, with three repetitions per model and scenario. Qwen passed 104/125 eligible attempts; Gemma passed 81/127. Six raw exclusions remain recorded: three Windows sandbox failures and three model-authored gate configurations that the harness classified as infrastructure failures. Qwen's complex-work suite has no eligible custom-gate attempt, so that suite's headline is withheld while all its observations remain available.

Download the scorecard data and full run data with judging and performance. The companion includes per-trial fixed scores, both advisory judge ledgers, scenario and repetition results, latency, throughput, RAM/GPU measurements, postmortems and review audits. Known setup and evaluator problems remain visible beside the frozen results. Different review rubrics stay separate; misaligned A/B and incidental fixture-page opinions are excluded from the website's quality means and retained in the download.

A separate six-trial activation subset exposed the missing DocBlocks tools and produced two Qwen passes and no Gemma passes. It does not replace the original six setup failures. Binary repair messages were rejected before delivery; the postmortem distinguishes that framework limitation from initial schema and grounding errors. All trials and judging are complete.

Both models ran on Windows with a Radeon AI PRO R9700 and native 0.1.54. The task tables show engine-log measurements across all attempts; system RSS and GPU memory remain separate, and one GPU observation is missing. Download notes and validation explain all denominators, review selections, timing limitations and the frozen capability implementation's differences from its prose rubric.
