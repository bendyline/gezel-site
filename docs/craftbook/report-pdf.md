# Formatted Report

Produce a polished, print-ready PDF report from Markdown with DocBlocks — no hand-built HTML or browser print translator. Locks the audience, source facts, structure, and acceptance criteria first; writes the complete report as report.md; then converts, previews, and saves report.pdf in the project's artifacts drawer.

## How it runs

| # | Step | Who runs it | What happens |
| --- | --- | --- | --- |
| 1 | Outline the report | Planner | Lock the audience, source facts, section order, and acceptance criteria. |
| 2 | Write the Markdown report | Copywriter | Write the complete {{sourceOutputPath}} source to the locked outline. |
| 3 | Publish the PDF | Copywriter | Convert the approved source, inspect and preview it, and save the real binary deliverables with review evidence. |
| 4 | Evaluate | Reviewer | Review saved-file integrity and content fidelity; document the limits of reconstructed or first-frame previews. |
| 5 | Finish | Copywriter | Deliver the saved files with the recorded review evidence and limits. |

Say something like "formatted report" or "make a pdf report" or "create a pdf" or "export this report to pdf" or "quarterly report" or "printable document" or "report with cover page" in chat to start it.

Needs toolsets: `docblocks`.
