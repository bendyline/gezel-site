# Structured Interview Kit

Write a structured interview kit for one role from the hiring desk: a job description built on the role's job-related requirements, two questions per requirement with follow-ups, a 1-to-4 scorecard with what each score looks like, and the questions to leave out. Every candidate gets the same questions and is rated on the same evidence; the person hiring makes the decision.

## How it runs

| # | Step | Who runs it | What happens |
| --- | --- | --- | --- |
| 1 | Write the job description | Developer | the role's job-related requirements, duties and terms as the desk records them |
| 2 | Write the interview kit | Developer | the same questions for every candidate, and a scorecard tied to the requirements |
| 3 | Finish | Developer | Stamp a short summary and report DONE. |

Say something like "interview kit" or "interview questions" or "structured interview" or "scorecard for" or "job description for" in chat to start it.
