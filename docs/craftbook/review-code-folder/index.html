Review a code folder

Run this in GezelNothing opened? Opening from this site needs the latest Gezel. Get Gezel

A careful colleague's review of a folder of code: a short summary, each real problem with its file and line, how serious it is, what goes wrong and a suggested fix, and what the code does well. It reads the code without running it and reports only problems it can point to in a line.

Say something like "review a code folder" or "review this folder of code" or "find bugs in this code" or "what is wrong with this code" in chat to start it.
