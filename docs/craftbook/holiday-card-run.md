# Holiday Card Run

Make the December run a pleasure instead of a panic: sweep the address list while there is still time to fix it, settle the card message, and produce the print-ready card and the address sheet in one sitting. Locks the roster sweep and the message criteria FIRST, then builds the card, then the address sheet, then reports the gaps that still need a human. Use for holiday cards, the annual card run, 'time for the holiday cards', address list cleanup before card season, and the December mailing.

## How it runs

| # | Step | Who runs it | What happens |
| --- | --- | --- | --- |
| 1 | Sweep the roster | Copywriter | who's in, stale or missing addresses, message criteria |
| 2 | Build the card | Designer | print-ready card front and inside message |
| 3 | Build the address sheet | Developer | print-ready address sheet, roster fixes recorded |
| 4 | Write the run summary | Copywriter | what went to print, gaps that need a human |
| 5 | Evaluate | Reviewer | Grade the deliverable against every acceptance criterion. All pass → finish; any fail → loop back and fix the gap. |
| 6 | Finish | Developer | All acceptance criteria met. Stamp a short summary and report DONE. |

Say something like "run the holiday cards" or "time for the holiday cards" or "holiday card run" or "make the card and the address sheet" or "december card season" in chat to start it.
