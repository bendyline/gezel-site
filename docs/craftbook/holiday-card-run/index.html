Holiday Card Run

Make the December run a pleasure instead of a panic: sweep the address list while there is still time to fix it, settle the card message, and produce the print-ready card and the address sheet in one sitting. Locks the roster sweep and the message criteria FIRST, then builds the card, then the address sheet, then reports the gaps that still need a human. Use for holiday cards, the annual card run, 'time for the holiday cards', address list cleanup before card season, and the December mailing.

How it runs

#StepWho runs itWhat happens
1Sweep the rosterCopywriterwho's in, stale or missing addresses, message criteria
2Build the cardDesignerprint-ready card front and inside message
3Build the address sheetDeveloperprint-ready address sheet, roster fixes recorded
4Write the run summaryCopywriterwhat went to print, gaps that need a human
5EvaluateReviewerGrade the deliverable against every acceptance criterion. All pass → finish; any fail → loop back and fix the gap.
6FinishDeveloperAll acceptance criteria met. Stamp a short summary and report DONE.
