Reproduce-Then-Fix a Bug

Fix a bug the disciplined way, with proof at every step: a failing test that reproduces it (verified red by a real test run), the smallest change at the real defect site, a green suite afterwards, and an enforced independent review of the fix.

How it runs

#StepWho runs itWhat happens
1Reproduce with a failing testDeveloperEstablish the failure on the real code, as a running test that fails for the right reason.
2Locate the defectResearcherName the defect site and the causal chain from it to the symptom. No source edits.
3Make the smallest fixDeveloperChange the real defect site, minimally, keeping the new test as a regression guard.
4Validate red-to-greenDeveloperRe-run the original reproduction and the whole suite; record the real results.
5Evaluate the deliverableReviewerIndependently grade the observable deliverable and route it to finish, repair, or user escalation.
6Repair the deliverableDeveloperFix only the concrete gaps from the latest independent review.
7FinishDeveloperAll deterministic and reviewer criteria passed.
8Escalate unresolved concernsDeveloperThe bounded repair loop ended without a defensible pass.

Say something like "fix this bug" or "reproduce and fix" or "tdd bug fix" or "write a regression test" or "debug and fix" in chat to start it.
