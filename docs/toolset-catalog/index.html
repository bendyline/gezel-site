Add-on toolsets and connectors

Every gezel starts with the built-in tool groups that fit its role, described in Tools and toolsets. This page lists what you can add on top.

Add-on toolsets

Extra tools from Gezel’s own catalog. Add one to a gezel from its Toolsets tab.

ToolsetWhat it does
DocBlocks DocumentsCreate real documents and rendered media from markdown — Word (DOCX), PowerPoint (PPTX), PDF, Excel (XLSX), EPUB, HTML, MP4, animated GIF, and dashboard PNG images — via the DocBlocks MCP server.
GitHubBrowse and act on GitHub repositories, issues, and pull requests via the official @modelcontextprotocol/server-github MCP server.

Connectors

Connectors copy data from outside services, such as mail, calendars and issue trackers, into a project as searchable files. Your crew works on that local copy, never on the live account.

ConnectorWhat it brings in
Airtable RecordsMirror an Airtable table into a searchable corpus — one file per record — via the Airtable API, hosted off-platform through a vendored Prismatic component.
Azure Monitor LogsMirror a Log Analytics workspace table — request logs, diagnostics, app telemetry — into a queryable data table.
Bluesky PostsKeep a searchable copy of your Bluesky presence: your posts with their likes and reposts, mentions and replies from others, and a daily follower count.
Email (IMAP)Mirror an IMAP mailbox into a normalized, searchable corpus of messages.
GitHub IssuesMirror recent issues from one GitHub repository into searchable project files.
GitHub Pull RequestsMirror a project's open pull requests into local files: a summary, one file per changed file with its patch, and the complete unified diff.
GitHub ReleasesMirror GitHub release notes and uploaded release assets into local project files.
GitHub WikiMirror a repository's wiki pages into searchable project files.
GmailMirror a Gmail mailbox into a normalized, searchable corpus of messages (OAuth).
Google CalendarMirror Google Calendar events into a normalized, searchable corpus (OAuth).
Instagram MediaKeep a searchable copy of your Instagram presence: your posts, reels, and carousels with captions, links, like and comment counts and a daily engagement history, plus a daily follower count.
JSON Rows over HTTPMirror rows from any JSON or NDJSON HTTP endpoint into a queryable data table.
Linear IssuesMirror recent Linear issues into a searchable corpus via Linear's MCP server.
LinkedIn PostsPublish to LinkedIn from Gezel: your crew drafts posts in your voice, and with your permission queues them — every publish still asks for your consent before anything goes out.
Microsoft 365 MailMirror a Microsoft 365 (work/school) mailbox into a normalized, searchable corpus of messages (OAuth).
Outlook.com MailMirror a personal Outlook.com mailbox into a normalized, searchable corpus of messages (OAuth).
X PostsKeep a searchable copy of your X (Twitter) presence: your posts with their like, repost, and view counts and a daily engagement history, optional mentions, and a daily follower count.

Community servers

Gezel’s toolset browser also lists about 12,900 MCP servers from the public community registry, marked Community. They are third-party projects, so review one before you add it to a crew. You can also bring your own: see Custom MCP toolsets.
