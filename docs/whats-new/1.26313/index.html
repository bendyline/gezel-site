Help / What's New

1.26313 — 9 November 2026

Connectors are no longer a preview. Every project can now bring in your mail, files, calendar, issues and feeds as searchable files, from a new Connections tab. Local models also run on AMD Radeon graphics through AMD's own ROCm engine, Qwen 3.8 Flash Next fits on Macs with far less memory, and a link on gezel.com can open the matching form in the app.

If you read only one thing: open a project's Connections tab and add the mailbox or folder the work depends on.

Connectors for every project

Until now, connectors appeared only after you turned on Show preview features. They are now part of every project. A project's new Connections tab lists its connections, its camera lookouts and its toolsets, which used to sit in the project's Settings tab. Add connection offers:

  • Mail: Gmail, Outlook, Microsoft 365, and any mailbox that supports IMAP.

  • Files and calendars: Google Drive, OneDrive, SharePoint, and Google and Microsoft calendars.

  • Work trackers: GitHub issues, pull requests, releases and wikis, Linear, and Airtable.

  • Feeds and posts: RSS feeds, YouTube, Bluesky, Instagram, LinkedIn and X.

A connection copies what it reads into the project as ordinary files that your crew can search and cite, and keeps them up to date. Nothing connects until you add a connection, and each one fetches only from the account and folders you choose. Gezel ships no sign-in app of its own for Google and Microsoft, so those connections ask you to register one with the provider first; the form shows the steps and the address to paste. A mail connection sends only to the recipients and domains you allow, and a reply can be saved to your drafts for you to send yourself. What leaves this computer covers the network side.

The projects and craftbooks that use a connector appear for everyone too. New Project now offers E-Mail, which links a mailbox and adds a Mail tab to the project, and Sales Pipeline, one of whose craftbooks can read your calendar. Pull Request Review, Meeting Prep Brief, Plan the Week, Social Digest and the other craftbooks that can work from a connection now appear in New Task and on Home's Create tab.

Show preview features in Settings → About stays. It now covers one preview, Channels, which lets your crew send messages to a webhook such as a Slack channel or a phone notification service.

Local models on AMD Radeon graphics

On a Windows or Linux computer with a recent AMD graphics card, the desktop app now runs local models on the card through ROCm, AMD's own compute engine. It covers the Radeon RX 7000 and Radeon Pro W7000 series, the Radeon RX 9000 series and Radeon AI PRO R9700, the Radeon 780M and 760M graphics built into many Ryzen laptops, and Ryzen AI processors such as Strix Halo.

Older Radeon cards keep the Vulkan engine, which already ran them. When ROCm cannot be used, Vulkan runs instead and Settings → This PC (llama) says why. On Linux the usual reason is that your account is not yet in the render and video groups. On Windows, the command-line install uses ROCm too.

The ROCm engine is why the Windows and Linux downloads for Intel and AMD computers are larger in this release, by about 140 MB on Windows and 160 to 240 MB on Linux.

A large model on a Mac with less memory

Qwen 3.8 Flash Next, the 180-billion-parameter Qwen that runs on the DwarfStar engine, can now run on a Mac that cannot hold all of it. Gezel keeps the parts it uses most in memory and reads the rest from the SSD as it works, so it needs about 23 GB of memory instead of nearly 50 GB. On a Mac with room for the whole model, it still loads all of it.

Gezel now plans memory for the large DwarfStar models from measurements of how much each really uses, with the whole model in memory and when streaming. It sizes the cache to fit, and declines a model the computer cannot hold, with a message saying so, instead of starting it and running out of memory.

Open Gezel from gezel.com

Gezel now opens gezel:// links. A link to a craftbook, a project type or a Help article opens that form or article in the app, so a page on gezel.com can take you straight to it. A link only opens the form. You still choose to start, and a link never runs, installs or downloads anything. On Windows, the app registers the link type for your account when it runs, and uninstalling removes it.

Smaller things

  • Home's Make something tab is now called Create.

  • The Activity panel reads at a glance: what needs you is tinted rose, work underway and next is amber, and what is ready is green. A section's light is on only when it holds something.

  • The message box keeps its expanded size when you switch between chat and the terminal.

  • Files a conversation used or made show a thumbnail when they are pictures.

  • Model lists can group models under headings and describe each one. Claude's list is the first to use it.

  • File lists have a Copy file path action, and documents can be shown in Finder or File Explorer.

  • A task that is running opens on its chat, where the work is happening.

  • Code, keyboard shortcuts and error messages can be selected and copied anywhere they appear.

  • Background indexing shows one row per project in Activity.

  • While you edit a document, it uses the app's own font. Its theme still applies when you play, preview or export it.

  • Picture models that can only edit, such as Qwen Image Edit, are no longer used to draw a new picture.

  • On a Mac, a conversation with pictures no longer looks full long before it is.

  • A folder with Swift code no longer crashes gezel's indexing, which could restart it many times a day.

  • Opening a project no longer sometimes shows "Gezel API transport unavailable … Failed to fetch". The Toolsets panel now loads only the toolsets it shows instead of the whole community registry, and large lists arrive compressed.

  • A scheduled job whose first step names no specialist now starts with the schedule's gezel, instead of sitting idle and holding back every later run.

  • A review that marks a check FAIL under a heading such as Sources or References now fails, where before that line could be skipped.

  • On a Mac, when a gezel running on the computer's own model hands work to others, its closing message names them.

  • Toolsets you add from an online server now work in GitHub Copilot and Claude Code sessions too.

  • The on-device engines are updated: llama.cpp 0.9.0, stable-diffusion.cpp master-1050 for pictures, and mlx-vlm 0.7.12 on Macs.

Privacy and security

  • Camera pictures and paired computers. A paired server is now treated like a cloud engine: unless you let cloud AI see a camera's pictures, it does not get them when a gezel asks it for a picture. More in Cameras and lookouts.

  • Claude Code sessions use only Gezel's tools. A gezel running on Claude Code used to pick up your own MCP servers and claude.ai connectors, such as Gmail and Drive, past your security settings. It now gets only the tools Gezel gives it.

  • Sign-in on a Docker install counts every attempt in a burst before checking the password, so a burst of guesses reaches the lockout like single tries do.

  • A daily check now also scans our published Docker images for known vulnerabilities.

Gezel in Docker

  • The port is now 6230. Images before this one answered on 6228. Start the container with -p 127.0.0.1:6230:6230 and sign in at http://localhost:6230. To keep 6228, add -e GEZEL_CONTAINER_PORT=6228 and map 6228. Your accounts, keys and work carry over. Gezel in Docker has the full command.

  • A second container started on a volume another container is using now stops with a message to run commands in the first one with docker exec.

  • A bare docker exec gezel gezel run … now lands in the Default project, instead of creating a project named "work" with a crew of its own.

In the terminal

  • The command line installs with a short name: npx gezel-cli. gezeld and gezel-mcp are short names for the daemon and the MCP server.

  • Add --download, or set GEZEL_AUTO_DOWNLOAD=1, and a command that needs a model downloads the engine and the model that fits this computer without asking. It suits scripts, containers and AI agents running Gezel for you.

  • On a Mac whose engine toolkit is missing its Python helper, gezel run now says so and --download fetches it, instead of every message failing.

  • A craftbook name with a typo no longer starts the daemon before saying it found nothing.

  • gezel app guide prints the guide to building a Gezel app for the version you installed.

For developers

  • Pages in Gezel apps get version 2 of the shared components: tabs, action forms in a dialog or inline, and collection filters that appear once a list is long enough. Build a Gezel app gathers everything an outside builder or their agent needs, and the new Gezel app UX guide describes how an app page is organized.

  • @bendyline/gezel-capacitor is now a public npm package, with offline speech and knowledge catalogs for phone apps. Its speech plugin is named GezelOfflineSpeech.

  • In the app SDK, openChat() with no gezel or role now talks to the project's lead.

Things to see and do after update

  • Open a project's Connections tab and connect the mailbox, folder or tracker its work depends on.

  • On a Windows or Linux PC with an AMD Radeon card, look at Settings → This PC (llama) to see which engine runs your models.

  • If you run Gezel in Docker, change the port to 6230 when you pull the new image.
