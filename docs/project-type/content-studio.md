# Content Studio

Keep long-form content moving from idea to published, then make each piece work twice. A managing editor runs the pipeline, the editorial calendar and who is writing what, and plans the newsletter, social posts and video chapters every piece spins off.

**Crew it sets up**

| Role template | Crew lead |
| --- | --- |
| managing-editor | Yes — leads the project |
| copywriter | No |
| reviewer | No |
| illustrator | No |

**Plans it installs:** `blog-post`, `newsletter-issue`, `case-study`, `seo-meta-pack`, `copy-review`, `social-thread`
