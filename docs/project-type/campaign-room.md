# Campaign Room

Run one marketing campaign from plan to results. A campaign manager keeps the goal, a channel calendar, every asset from idea to live, the budget against what was spent, and the results day by day in one room, so a launch never rests on anyone’s memory.

**Crew it sets up**

| Role template | Crew lead |
| --- | --- |
| campaign-manager | Yes — leads the project |
| omroeper | No |
| copywriter | No |
| designer | No |

**Plans it installs:** `ad-variations`, `email-sequence`, `landing-copy`, `social-thread`
