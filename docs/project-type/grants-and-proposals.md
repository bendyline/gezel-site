# Grants & Proposals

Find grants, write proposals and meet every deadline. A fundraiser tracks each funding opportunity and request for proposals with its deadline, fit and ask, keeps a requirements checklist for every submission, records what was awarded, and reminds you two weeks before the next deadline.

**Crew it sets up**

| Role template | Crew lead |
| --- | --- |
| aanjager | Yes — leads the project |
| researcher | No |
| copywriter | No |

**Plans it installs:** `research-report`, `proposal-sow`, `evidence-brief`
