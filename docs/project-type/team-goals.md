# Team Goals

Set your team's goals and check progress toward them. A planner keeps each goal's key results, current against target, logs the weekly check-ins, and turns what a meeting agreed into actions with an owner and a date.

**Crew it sets up**

| Role template | Crew lead |
| --- | --- |
| planner | Yes — leads the project |

**Plans it installs:** `weekly-review`, `status-report`, `meeting-notes-to-actions`, `standup-summary`, `kpi-scorecard`
