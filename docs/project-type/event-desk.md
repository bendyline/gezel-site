# Event Desk

Run a business event, from a client summit to a team offsite or a launch party. An event planner compares the venues, keeps every vendor with its contract and deposits, tracks RSVPs and dietary needs, holds the run of show, and shows the budget against what is signed.

**Crew it sets up**

| Role template | Crew lead |
| --- | --- |
| ceremoniemeester | Yes — leads the project |
| kantoormeester | No |
| copywriter | No |

**Plans it installs:** `run-of-show`, `invitation-design`, `comparison-matrix`
