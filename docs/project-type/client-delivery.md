# Client Delivery

Deliver client work on time, with every handoff tracked. A planner keeps each client project with its milestones, counts how long every approval has waited on the client, names what is late, and drafts the weekly status each client gets.

**Crew it sets up**

| Role template | Crew lead |
| --- | --- |
| planner | Yes — leads the project |
| copywriter | No |

**Plans it installs:** `status-report`, `meeting-notes-to-actions`, `proposal-sow`, `case-study`
