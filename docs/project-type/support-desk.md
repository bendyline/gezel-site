# Support Desk

Answer customer questions and keep every request moving. A support lead logs each question as a ticket, drafts replies from your own help articles, and notices the questions those articles do not answer yet.

**Crew it sets up**

| --- | --- |
| support-lead | Yes — leads the project |
| boekwachter | No |

**Plans it installs:** `inbox-triage`, `faq-from-docs`, `knowledge-base-article`
