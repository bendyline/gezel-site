# Hiring Desk

Run a hiring round from the job post to the signed offer. A recruiter keeps each open role’s pipeline, books interviews, gathers scorecards tied to the role’s requirements, and drafts the interview kit and the offer, while you make every decision.

**Crew it sets up**

| Role template | Crew lead |
| --- | --- |
| recruiter | Yes — leads the project |
| mock-interviewer | No |

**Plans it installs:** `structured-interview-kit`, `contract-template`
