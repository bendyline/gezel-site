# Sales Pipeline

Follow every deal from first contact to close. An account manager keeps each deal’s stage, value and next follow-up, tells you who to call today, and keeps a weighted forecast you can plan the month around.

| Role template | Crew lead |
| --- | --- |
| account-manager | Yes — leads the project |
| researcher | No |

**Plans it installs:** `proposal-sow`, `meeting-prep-brief`, `lead-enrichment`
