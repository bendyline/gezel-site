Qwen 3.8 (27B, Q4)

Alibaba's Qwen 3.8 at 27B parameters: a dense, multimodal agentic model with native text, image, and video understanding, 262K context, flexible reasoning effort, MTP, and native tool calling. Q4_K_M is the practical on-device build for machines with 24GB+ usable memory.
