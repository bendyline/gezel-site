Qwen 3.5 (2B, Q4)

Alibaba's Qwen 3.5 at 2B parameters. Multimodal (text + images) with native tool calling and a 256K context window. A very compact choice for constrained devices.

At a glance
Made byAlibaba
Download size1.3 GB
Parameters2B
QuantizationQ4_K_M
Context window256K tokens
Uses toolsYes
Best forEveryday work
Runs onllama.cpp, MLX, Ollama
LicenseApache 2.0
Added to the catalog2026-08-15

Gezel downloads this model the first time it is needed, checks the file against its published hash, and applies tuned settings for it.
