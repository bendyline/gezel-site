Qwen 3.5 (4B, Q4)

Alibaba's Qwen 3.5 at 4B parameters. Multimodal (text + images) with native tool calling and a 256K context window. A balanced compact default for modern laptops.

At a glance
Made byAlibaba
Download size2.8 GB
Parameters4B
QuantizationQ4_K_M
Context window256K tokens
Uses toolsYes
Best forEveryday work
Runs onllama.cpp, MLX, Ollama
LicenseApache 2.0
Added to the catalog2026-08-15

Gezel downloads this model the first time it is needed, checks the file against its published hash, and applies tuned settings for it.
