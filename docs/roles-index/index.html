Handboek / Gezel Roles

Roles at a glance

A gezel's role is its trade: the bundle of skills, tools, and habits it brings to your crew. Roles aren't just labels — each one comes with a default character, a curated toolkit, and a model floor (the minimum model tier the role needs to work unsupervised).

RoleWhat they doModel floorDefault craftbooks
MeesterCoordinator: delegates work across the gezel workforce; does not build directly.mediumstatus-report, weekly-review
VoormanForeman: triages, diagnoses, and routes work to specialists; read-only investigator.mediumroot-cause-investigation, release-readiness-review, bug-fix-tdd
ReviewerReviews code and deliverables; verifies claims against sources before approving.mediumpull-request-review, code-review, deep-security-review, pr-security-review, test-coverage-review
ResearcherAnswers questions from sources; cites every claim and grounds facts in authorized inputs.mediumresearch-report, literature-review, competitive-analysis, due-diligence-brief, fact-check
CopywriterDrafts comms and marketing copy under length/tone constraints.smallblog-post, landing-copy, press-release, email-sequence, product-descriptions
DesignerDesigns visual deliverables; generates and places imagery into pages.smallhero-image, landing-page, moodboard, svg-animation, logo-set
Image GeneratorProduces images via generate_image; no direct file writes.tinylogo-set, icon-pack, hero-image, thumbnail-generator
Video GeneratorProduces short video clips via generate_video; no direct file writes.tiny—
DeveloperBuilds and fixes code; works to task-specific build and test gates.smallbuild-loop, bug-fix-tdd, refactor-module, test-suite-backfill, apply-review-findings
Web DeveloperFrontend/full-stack code with live browser work.smalllanding-page, spa-dashboard, web-app-crud, portfolio-site, pwa-offline
PlannerTurns a brief into a structured, owned, checkable plan.mediumspec-doc, proposal-sow, dashboard-spec, board-deck, onboarding-checklist

Each role has its own article in this section with the full picture: the character it starts with, every tool in its kit, and the craftbooks it runs well. And roles are starting points, not cages — you can rename, re-equip, and rewrite any gezel after it's created.
