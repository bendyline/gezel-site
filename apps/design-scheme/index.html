Design Scheme

Explore color schemes and design directions with a designer. Palettes are saved as artifacts and shown on a live gallery.

Get GezelRead about it in the docs →

Try it

Open in a full window ↗

Design Scheme running in your browser on sample data. Use the page, or talk with the designer beside it: the conversation is scripted for this preview, and the changes stay in the page.

What’s inside

The crew

  • Designer Crew leadThinks in layout, hierarchy, and visual tone.

Actions the crew can take

  • Save schemeSave a named color scheme so it shows on the gallery.

Each action is a small script that changes the app’s files, checked by Gezel’s security settings before it runs.

Files it keeps

Plain files in the project folder you can open, back up, and read: schemes/index.json, schemes/warm-dusk.json.

Start one

  1. Download Gezel for Mac, Windows or Linux. It’s free.
  2. Choose New project, then Photos & Media, then Design Scheme.
  3. Answer its question: What are you designing?
  4. Your designer takes it from there, on the model you choose.
