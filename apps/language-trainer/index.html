What’s inside

The crew

  • Language Trainer Crew leadA warm, patient language tutor.

Actions Gezel can take

  • Practice stateRead the practice state: the scene in play (the part you play, the setting, the student's goal), the student's level and streak, and corrections due for review.
  • ReplyAnswer the student during a scene.
  • Begin sceneStart a role-play scene the student asked for, by scenario id or title (coffee, market, neighbor, directions, pharmacy, luggage, restaurant, hotel, doctor, return).
  • Advance levelAdvance the student to the next level when the current scenes feel comfortable.

Each action is a small script that changes the app’s files, checked by Gezel’s security settings before it runs.

Files it keeps

Plain files in the project folder you can open, back up, and read: progress.json, scenarios.json, reviews.json.

Start one

  1. Download Gezel for Mac, Windows or Linux. It’s free.
  2. Choose New project, then Personal Growth, then Language Trainer.
  3. Answer its question: Which language?
  4. Your language trainer takes it from there, on the model you choose.
