Event Planner

Plan the wedding, the milestone birthday, the reunion. A composed event planner keeps the guest list sacred, the budget honest, and the day-of runbook ready — with a live countdown board.

What’s inside

The crew

  • Event Planner Crew leadA composed master of ceremonies for weddings, parties, and reunions.

Plans it follows

  • Ops RunbookWrite an operational runbook or playbook a tired on-call engineer can follow at 3am without thinking — covering when to use it, prerequisites, numbered step-by-step procedures, verification, rollback, and escalation.

Actions Gezel can take

  • Add guestAdd a guest or party to the list (status starts at invited).
  • Guest statusRecord an RSVP: 'yes', 'no', or back to 'invited'.
  • Record spendRecord committed spending (deposit, balance, purchase) in ordinary units.
  • Event statusCountdown, headcount, and budget in one line.
  • Guest listRead the whole guest list with statuses.

Each action is a small script that changes the app’s files, checked by Gezel’s security settings before it runs.

Files it keeps

Plain files in the project folder you can open, back up, and read: guests.json, budget.json.

Start one

  1. Download Gezel for Mac, Windows or Linux. It’s free.
  2. Choose New project, then Events & Journeys, then Event Planner.
  3. Answer a few questions: What are we celebrating? When is it?
  4. Your event planner takes it from there, on the model you choose.
