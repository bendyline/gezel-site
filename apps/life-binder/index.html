What’s inside

The crew

  • Archivist Crew leadA gentle, rigorous archivist for the file nobody wants to need — wills, policies, accounts, instructions.

Plans it follows

  • Annual Document ReviewWalk a life binder's document roster once a year: inventory what is present and missing, confirm each present document is still current (right beneficiaries, right address, not expired), record the review so staleness tracking resets, and produce a prioritized to-do for the gaps.

Actions Gezel can take

  • Record documentRecord that a document exists and where the original lives.
  • Mark missingMark a checklist item as a known gap.
  • Mark reviewedConfirm a document was just reviewed and is current.
  • Binder statusThe completeness picture: what's in place, missing, or due a review.
  • ChecklistRead the whole checklist with locations.

Each action is a small script that changes the app’s files, checked by Gezel’s security settings before it runs.

Files it keeps

Plain files in the project folder you can open, back up, and read: documents.json.

Start one

  1. Download Gezel for Mac, Windows or Linux. It’s free.
  2. Choose New project, then Money & Small Business, then Life Binder.
  3. Answer its question: Who is this binder for?
  4. Your archivist takes it from there, on the model you choose.
